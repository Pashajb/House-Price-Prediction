# Comparative Statistical Modeling of Residential Property Prices in Tehran and Shiraz

## Overview

This project investigates residential apartment listing prices in Tehran and Shiraz, Iran, using statistical analysis and machine learning.

The main objective is to examine how structural, geographical, and temporal characteristics of residential properties are associated with their advertised prices.

## Research Questions

- Which property characteristics are most strongly associated with listing prices?
- How do advertised apartment prices differ between Tehran and Shiraz?
- How accurately can statistical and machine learning models predict listing prices?
- Do the relationships between property characteristics and prices differ across the two cities?

## Dataset

The project uses the Divar Real Estate Ads dataset.

**Source:** [Divar Real Estate Ads – Hugging Face](https://huggingface.co/datasets/divarofficial/real_estate_ads)

The analysis focuses on residential apartment sale advertisements in Tehran and Shiraz.

Advertised prices do not necessarily represent final property transaction prices.

## Methodology

The planned workflow includes:

1. Data acquisition and validation
2. Data cleaning and preprocessing
3. Exploratory data analysis
4. Statistical analysis
5. Regression and machine learning
6. Model evaluation and comparison
